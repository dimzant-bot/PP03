- Вывод о свойствах кода и выборе среды для каждой операции —
В ходе работы установлено, что Visual Studio Code удобен для навигации по коду, переименования переменных и проверки синтаксиса. Apache NetBeans использовался для рефакторинга с выделением отдельного метода и форматирования кода.
Выделение calculateFine() позволило отделить расчёт штрафа от основной логики возврата книги. Метод returnBook() стал отвечать за обработку возврата и обновление базы данных, а calculateFine() — за вычисление штрафа.
Такое разделение улучшает читаемость, упрощает тестирование отдельных частей программы и дальнейшее сопровождение проекта.
Общие настройки, сохранённые в Git-репозитории, позволяют использовать единые правила форматирования и проверки кода в обеих IDE.
