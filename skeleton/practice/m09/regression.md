После рефакторинга выполнено переименование `$msg` в `$message` в Visual Studio Code и выделение метода `calculateFine()` в Apache NetBeans.

В результате:

- NLOC метода `returnBook()` уменьшилось с 34 до 23.

- Проверка `php -l` не выявила синтаксических ошибок.

## Повторная проверка после замечаний ревьюера

Повторно рассмотрены следующие аспекты:
1. Сохранение условия начисления штрафа только для категории `student`.
2. Сохранение строгого сравнения дат `$today > $due`.
3. Сохранение ставки штрафа `FINE_PER_DAY`.
4. Сохранение порядка обновления таблиц `loans` и `copies`.
5. Сохранение структуры JSON-ответа с полями `ok`, `message`, `fine`.
6. Отдельная проверка поведения интерфейса после успешного возврата книги.

Изменения структуры кода не должны влиять на фактическое поведение системы. Основная логика возврата осталась в `returnBook()`, а вычисление штрафа перенесено в `calculateFine()`.
