# М08 · Протокол характеризационных проверок

- SHA, версия среды, дата и часовой пояс (для логики дат) —
SHA: требуется зафиксировать командой git rev-parse HEAD.
Версия PHP: php -v.
Версия браузера: Microsoft Edge.
Дата наблюдения: 26.11.2026.
Часовой пояс: Europe/Riga.
Логика дат: используется PHP date('Y-m-d') и часовой пояс среды PHP.
- Где взять учебные данные и как восстановить исходное состояние —
Учебные данные: таблицы loans, users, copies базы данных проекта.
Для проверок необходима существующая выдача книги.
Для повторного тестирования нужно подготовить выдачу с returned_at = NULL.
Для проверки просрочки установить due_at в прошедшую дату.
Для проверки обычного возврата установить due_at на текущую или будущую дату.
После проверки восстановить исходные значения записей базы данных.
- Команда запуска тестов или шаги ручной проверки —
1. Запустить проект локально согласно его настройкам.
2. Войти под пользователем с ролью библиотекаря.
3. Открыть страницу учебных выдач.
4. Нажать F12 → Сеть → Fetch/XHR.
5. Очистить журнал запросов.
6. Нажать «Принять» и подтвердить действие.
7. Найти запрос action=loan.return.
8. Проверить Payload, Response и Headers.
9. Проверить изменение строки выдачи в интерфейсе.
10. Проверить изменения в базе данных.

- Расхождения с документацией и передача результатов в М09
Штраф рассчитывается только для пользователей категории student.
Для расчёта используется количество полных дней просрочки.
Сравнение дат выполняется по календарным датам.
При успешном возврате изменяются таблицы loans и copies.
При успешном возврате интерфейс удаляет строку выдачи.
При наличии штрафа интерфейс показывает сообщение пользователю.
HTTP-статусы: 200 — успешный возврат, 422 — ошибка бизнес-логики, 403 — недостаточно прав.
