# М08 · Восстановление алгоритма

- Сценарий и его границы — возврат книги библиотекарем через кнопку «Принять» с подтверждением действия.
- Роль: библиотекарь.
- Вход: loan_id; запрос action=loan.return.
- Предусловия: библиотекарь авторизован; запись о выдаче существует; returned_at = NULL.
- Читаемые данные: запись выдачи из loans, пользователь из users, экземпляр из copies.
- Выход: JSON с полями ok, message, fine.
- Побочные эффекты при успешном возврате: обновление loans и copies.
- Правило штрафа: штраф начисляется только пользователю категории student, если текущая календарная дата строго больше даты возврата по сроку. Для расчёта используются полные дни просрочки.
- Исследованный SHA, версия среды и дата наблюдения — 66a0b2f8286f0c5ff8655f7265367ece9c0c3554
- Основная логика: LoanService.php, метод returnBook(int $loanId), строки 125–157 (по предоставленному отчёту).

## Псевдокод

```text
НАЧАЛО

1. Получить loan_id из запроса action=loan.return.

2. Прочитать запись о выдаче из loans,
   данные пользователя из users,
   данные экземпляра из copies.

3. Запись найдена?
   НЕТ:
       Вернуть ошибку «Запись не найдена».
       ЗАВЕРШИТЬ.
   ДА:
       Продолжить.

4. returned_at == NULL?
   НЕТ:
       Вернуть ошибку недопустимого состояния.
       ЗАВЕРШИТЬ.
   ДА:
       Продолжить.

5. Определить категорию пользователя.

6. Пользователь категории student?
   НЕТ:
       Штраф = 0.
   ДА:
       Сравнить текущую календарную дату
       с датой возврата по сроку.

       Текущая дата > даты возврата?
       НЕТ:
           Штраф = 0.
       ДА:
           Рассчитать количество полных дней просрочки.
           Рассчитать штраф по формуле из LoanService.

7. Обновить запись loans.

8. Обновить состояние экземпляра в copies.

9. Сформировать JSON-ответ:
   ok = true
   message = сообщение о принятии книги и штрафе
   fine = сумма штрафа.

10. Вернуть ответ браузеру.

КОНЕЦ
```

## Расхождения и вывод

Подтверждено предоставленным отчётом и характеризационной проверкой:
1. Штраф рассчитывается только для пользователей категории student.
2. Для расчёта используются полные дни просрочки.
3. Сравнение выполняется по календарным датам; начисление происходит только если текущая дата строго больше даты возврата по сроку.
4. При успешном возврате обновляются loans и copies.
5. В ответе при наличии штрафа указывается его сумма.
6. В проверке C02 сервер вернул ok=true и сообщение «Книга принята. Штраф: 6210 руб.», но строка выдачи осталась в интерфейсе.
Расхождение: ожидается исчезновение строки выдачи после успешного возврата, но фактически строка осталась. Причина по имеющимся данным не установлена. Для выяснения необходимо исследовать клиентский код: обработку JSON-ответа, обновление списка выдач и повторную загрузку данных.
