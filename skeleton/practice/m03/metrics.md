## 2. Где меняется каждая характеристика

Проверьте в обеих средах. Если среда чего-то не умеет — так и напишите: это тоже результат.

| Характеристика | VS Code | TODO вторая IDE |
|---|---|---|
| Кодировка файла | В строке состояния - UTF-8 | Tools - Options - Miscellaneous - Files - Default Encoding, для отдельных файлов зависит от настроек проекта и файла |
| Окончания строк (LF / CRLF) | В строке состояния → LF / CRLF | Зависит от настроек проекта и редактора; проверить фактические окончания строк файла |
| Табуляция → пробелы | Indentation → Convert Indentation to Spaces | Tools → Options → Editor → Formatting, настройки Tab Size и Expand Tabs |
| Форматирование файла | Format Document (Shift + Alt + F) | Source → Format (Alt + Shift + F) |
| Переименование переменной / метода | Rename Symbol (F2) | Refactor → Rename (Ctrl + R) |
| Выделение метода (Extract Method) | Code Actions / Refactor, зависит от языка и расширений | Refactor → Extract Method, если поддерживается для выбранного языка |
| Инспекция кода (поиск проблем) | Вкладка Problems | Окна Navigator, Output и подсветка ошибок редактора; дополнительные проверки зависят от языка и плагинов |
| Где хранятся настройки (файл / папка) | .vscode/settings.json, пользовательские настройки | Пользовательский каталог NetBeans, настройки проекта в nbproject (если используются) |
