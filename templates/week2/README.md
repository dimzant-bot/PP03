# Заготовки для модуля 4

| Файл | Куда положить | Для своего проекта |
|---|---|---|
| `.gitattributes` | корень проекта | подходит любому проекту |
| `.editorconfig` | корень проекта | проверьте размер отступа: JS/TS — обычно 2, Python, PHP, Java, C# — 4. Kotlin и C# держат здесь и правила линтера |
| `phpcs.xml` | корень проекта | только для PHP. Другой стек — файл правил своего линтера (методичка недели 2, п. 2.4) |
| `vscode/settings.json`, `vscode/extensions.json` | папка `.vscode/` в корне проекта | замените секцию `[php]` и список расширений на свои |
| `CONTRIBUTING.md` | корень проекта | подходит любому проекту |
