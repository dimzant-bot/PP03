## 3. Структура каталогов

| Папка / файл | Назначение |
|---|---|
| `backend/app/Http/Controllers/` | контроллеры API: `BookController`, `LoanController`, `AuthController` — вся логика запросов |
| `backend/app/Models/` | модели Eloquent: `User`, `Book`, `Copy` (экземпляр книги), `Loan` (выдача) |
| `backend/database/migrations/` | 9 миграций — структура БД; таблица `copies` добавлена позже остальных |
| `backend/routes/api.php` | все маршруты API (точка входа в логику) |
| `frontend/src/views/` | страницы: каталог, карточка книги, личный кабинет, панель библиотекаря |
| `frontend/src/api.js` | обёртка над Axios, базовый URL и токен — все запросы клиента идут через неё |
| `docker-compose.yml` | сервисы `app`, `mysql`, `nginx` |
| `.env.example` | шаблон настроек: БД, `APP_KEY`, почта |

## 6. Запуск

```
cp .env.example .env
docker compose up -d
docker compose exec app composer install
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate --seed
cd frontend && npm install && npm run dev
```

Проблемы: в README не было шага `key:generate` — без него сервер отвечал 500. Дописал в README (коммит `docs: дополнена инструкция запуска`).

## 7. Вывод о проекте

Проект небольшой (≈6 тыс. строк), с понятной структурой MVC и раздельными клиентом и сервером. Разработка остановлена полгода назад, а знание проекта сосредоточено у одного автора. Самая рискованная часть — выдача книг: `LoanController` чаще всего менялся и многократно исправлялся, бизнес-правила дописывались после ошибок. С него стоит начинать ревью. Инструкция запуска была неполной, Pull Request и теги не использовались — процесс разработки неформальный.
