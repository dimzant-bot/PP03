## Первый день (03.11)

1. Инструктаж по ТБ, подпись в карточке.
2. Установите программы из [docs/software.md](docs/software.md).
3. Скачайте этот репозиторий: `git clone <ссылка>` или кнопка Code → Download ZIP.
4. Выберите проект и согласуйте с руководителем. Сделайте форк в свой аккаунт и клонируйте **свой** форк.
5. Скопируйте шаблоны практики в свой проект (существующие файлы не перезаписываются):
   ```
   Windows:      powershell -ExecutionPolicy Bypass -File tools\install.ps1 C:\путь\к\вашему\проекту
   Linux/macOS:  bash tools/install.sh ~/путь/к/вашему/проекту
   ```
6. Закоммитьте и отправьте:
   ```
   cd путь/к/вашему/проекту
   git switch -c practice/m01
   git add practice .github
   git commit -m "chore: add practice skeleton"
   git push -u origin practice/m01
   ```
7. Добавьте руководителя в репозиторий (право чтения) и отправьте ему: ФИО, название проекта, ссылку на форк.
8. Впишите ФИО, проект и ссылку в бланк `docs/Документы_практики_ПП03.docx`, сохраните себе.
9. Начинайте [модуль 1](modules/m01.md).

**Требования к проекту:** клиент + сервер + база данных; не менее 2000 строк кода, 30 коммитов и README; запускается на вашем компьютере; у двух студентов не может быть одного проекта.


## Как сдать модуль

1. Проверка готовности (запускать из папки `pp03-ispo332`):
   ```
   python tools/check_practice.py путь/к/проекту --module 1
   ```
   Скрипт покажет, каких файлов нет, где остались `TODO`, есть ли отчёт и коммиты.
2. Отчёт: скопируйте `report-templates/report-M01.docx` как `ISPO332_Familiya_M01.docx` (фамилия латиницей), замените серые подсказки своим текстом, вставьте скриншоты.
3. Положите отчёт в `practice/m01/`, закоммитьте, влейте Pull Request, отметьте модуль в `practice/README.md`.

## Скрипты

Нужен Python 3.8+, сторонние библиотеки не нужны. Путь к проекту — аргументом.

| Скрипт | Что делает |
|---|---|
| `tools/install.ps1`, `tools/install.sh` | копирует `practice/` и `.github/` в проект |
| `tools/repo_stats.py` | авторы, ветки, теги, частота изменений файлов, активность, объём кода |
| `tools/metrics.py` | строки кода по языкам (сложность — если установлен `pip install lizard`) |
| `tools/check_practice.py` | проверка готовности модуля перед сдачей |

```
python tools/repo_stats.py C:\projects\library --out C:\projects\library\practice\m01\repo-stats.md
python tools/metrics.py C:\projects\library
```
