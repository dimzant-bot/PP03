# Программы для недели 1

Все программы бесплатные.

| Программа | Зачем | Где взять | Проверка |
|---|---|---|---|
| Git | контроль версий; в Windows вместе с ним ставится Git Bash | https://git-scm.com/downloads | `git --version` |
| VS Code | редактор | https://code.visualstudio.com | — |
| Python 3.8+ | скрипты практики; в Windows отметьте *Add python.exe to PATH* | https://www.python.org/downloads | `python --version` |
| XAMPP (или OpenServer) | запуск «Библиотеки КАИТ»: Apache + PHP 8 + MySQL + phpMyAdmin | https://www.apachefriends.org (версия с PHP 8.x); OpenServer: https://ospanel.io | панель XAMPP: Apache и MySQL — Running |
| Среда своего проекта | только если работаете со своим проектом | Node.js / PHP + Composer / JDK / .NET / Android Studio — что требует проект | `node -v`, `php -v` … |
| draw.io | диаграммы потоков данных (М2) | https://www.drawio.com или расширение VS Code *Draw.io Integration* | — |
| Браузер с DevTools | перехват запросов (М2) | Chrome, Edge, Яндекс Браузер или Firefox | F12 |
| Word или LibreOffice | отчёты | LibreOffice: https://www.libreoffice.org | — |

Необязательно: `cloc` (https://github.com/AlDanial/cloc/releases) — то же, что `tools/metrics.py`; `tree` — дерево каталогов.

Полезные расширения VS Code: *GitLens* (история и blame прямо в редакторе), *Draw.io Integration*, *Markdown Preview Enhanced*.
