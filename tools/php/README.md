# PHP_CodeSniffer

`phpcs.phar` (проверка стиля) и `phpcbf.phar` (автоисправление) — PHP_CodeSniffer 4.0.4,
https://github.com/PHPCSStandards/PHP_CodeSniffer, лицензия BSD-3-Clause.
Положены сюда, чтобы не скачивать их на каждом компьютере. Нужен PHP 7.2+ (в XAMPP есть).

Запуск из корня проекта, где лежит `phpcs.xml`:

```
php ПУТЬ\pp03-ispo332\tools\php\phpcs.phar --report=summary
php ПУТЬ\pp03-ispo332\tools\php\phpcbf.phar
```
