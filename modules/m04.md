## Шаг 6. Проверка в чистом окружении (3 ч) — в паре или самостоятельно
`git push -u origin practice/m04`, затем один из вариантов:
- **В паре:** партнёр клонирует ваш форк, запускает по `CONTRIBUTING.md`, форматирует 3–5 файлов → `git diff`. Потом наоборот.
- **Сам:** другой компьютер или пустой профиль VS Code (Profiles → New Profile, без копирования) →
  `git clone ссылка kait-check` → запуск только по `CONTRIBUTING.md` с отдельной БД → форматировать 3–5 файлов → `git diff`.

`git diff` пустой → скриншот `practice/m04/check-empty-diff.png`. Что пришлось угадывать — исправить в `CONTRIBUTING.md`.
